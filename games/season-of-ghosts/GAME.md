# Game Definition: Season of Ghosts

## System Identifier

- `system_id`: `pathfinder2e`
- `display_name`: `Pathfinder Second Edition`
- `game_id`: `season-of-ghosts`
- `game_name`: `Season of Ghosts`

## Purpose

This file defines the assumptions the planner should use when generating session plans for the named game `season-of-ghosts`, which uses Pathfinder 2e.

## Campaign Frame

- campaign type: published adventure path
- adventure title: `Season of Ghosts`
- default use case: campaign planning and session prep based on the GM's notes while reading the books
- planning model: Lazy GM / Return of the Lazy Dungeon Master eight-step structure
- scene model: prep should flow from scene to scene with flexible forks, not a rigid script

## Source And Canon Rules

When working in this folder, use this source priority:

1. the GM's explicit instructions and current request
2. files in `continuity/` for established table canon
3. files in `plans/` for session-facing prep history
4. files in `references/` for reading notes, extracted book details, and supporting material
5. general Pathfinder 2e assumptions

Important handling rule:

- this is a published campaign, but campaign notes should still be organized for practical table use
- avoid dumping large chunks of published text into plans
- prefer concise, original summaries and prep-ready bullets
- once the GM provides campaign notes, use those notes as the working basis for session prep
- if a detail from the published adventure has not yet been captured in local notes, treat it cautiously rather than assuming it belongs in active canon

## Core Rules Guardrail

When generating output for this folder:

- use Pathfinder 2e terminology
- use Pathfinder 2e style stat blocks or base-game-equivalent creature references
- keep rewards and treasure close to PF2e baseline expectations unless the GM explicitly asks otherwise
- do not use D&D 5e mechanics, stat formatting, or reward assumptions
- default to standard Pathfinder 2e creature and treasure expectations

## Terminology

Prefer terms like:

- AC
- HP
- Perception
- saving throws
- DC
- class DC
- level
- actions and reactions
- initiative
- strikes
- spell DC
- hazard
- loot

Avoid D&D 5e-specific terms unless the user explicitly asks for conversion.

## Session Planning Rules

- always begin session-planning work with a clarifying phase
- ask at least 10 clarifying questions and no more than 20 before drafting a session plan
- do not outline or draft the session plan until the GM has had a chance to answer those questions
- if some answers are missing, proceed with reasonable assumptions and state them briefly
- when notes exist in this game folder, use them to maintain continuity between sessions
- default pacing target is roughly 3 prepared scenes per hour of expected play, adjusted for encounter complexity
- each prepared scene should include a short read-aloud opener and a clear player-facing hook
- action scenes should use round-structure prep with a stage-setter and 3-5 complications when helpful

## Campaign Assumptions

- tone baseline: eerie rural horror with community focus
- structure baseline: mystery, tension, investigation, and survival pressure can matter as much as combat
- prep bias: practical table support over lore completeness
- continuity bias: preserve recurring NPCs, unresolved clues, local relationships, and consequences from prior sessions

## Threat And Stat Expectations

- combat-ready enemies should have PF2e-usable stat blocks or direct base-game references
- threats may include monsters, haunts, hazards, curses, environmental danger, social strain, scarcity pressure, and mystery clocks
- if a full stat block is too large for the session plan, provide a clear base-creature reference plus only the most relevant adjustments

## Reward Expectations

- rewards should feel plausible for PF2e baseline progression
- treasure should stay close to the game's expected economy and itemization unless the GM explicitly wants something unusual
- non-material rewards such as trust, access, revelations, local aid, ritual knowledge, and community leverage are especially appropriate when they fit the campaign

## File Usage Guidance

- use `continuity/` for table canon, durable NPCs, locations, factions, party state, and lasting truths
- use `plans/` for session prep documents and `session-arc-history.md`
- use `references/` for reading notes, chapter summaries, supporting extracts, and prep-adjacent material that is not yet established canon

## Output Style

- practical prep first
- concise bullets over paragraphs
- skimmable at the table
- original wording, not reproduced published text
- continuity-aware and spoiler-aware based on what the GM has already noted
