# Spearhead Web

Local-first Next.js app for running `Warhammer Age of Sigmar: Spearhead` matches.

## Scripts

- `npm run dev`
- `npm run lint`
- `npm run build`

The app runs on port `3001` for both development and production start.

## Current Scope

- branded app shell
- supported army selector
- local match creation and resume
- placeholder game runner route
- initial data model for `Stormcast Eternals: Vigilant Brotherhood`

## Notes

- V1 supports five Spearheads only
- battle tactic and twist handling will be manual
- full warscroll ingestion is still in progress
